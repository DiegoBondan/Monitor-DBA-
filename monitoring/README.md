# Monitoramento

Objetivo da primeira versão:

1. Verificar se o Supabase responde.
2. Medir latência.
3. Registrar HTTP status.
4. Identificar online/offline/degraded.
5. Depois persistir os resultados na tabela `monitoramento`.
6. Evoluir para métricas, alertas e histórico.

## Próximas métricas

- disponibilidade
- latência média
- quantidade de erros
- requisições
- sessões ativas
- usuários online/offline
- histórico por período
